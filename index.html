Install

Psaltercast isn't signed by Apple or Microsoft yet, so your computer asks once before opening it.

Psaltercast used to be called Lucerna: versions up to 0.0.4 still use that name for their files.

  1. Open the downloaded .dmg and drag Psaltercast into Applications.
  2. The first time, right-click Psaltercast in Applications and choose Open, then Open again.

For Macs with Apple Silicon (M1 or newer).

If macOS says the app is damaged, run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Psaltercast.app
  1. Unzip the downloaded .zip somewhere you keep programs, for example C:\Program Files\Psaltercast.
  2. Run psaltercast.exe. If SmartScreen appears, click More info, then Run anyway.

Windows 10 or 11, 64-bit.

  1. Make the downloaded AppImage executable, then run it:
chmod +x Psaltercast-*-linux-x86_64.AppImage
./Psaltercast-*-linux-x86_64.AppImage

64-bit x86 Linux. Some distributions need libfuse2 to run AppImages.

Plug in a projector or TV as a second screen, and Psaltercast shows the output there in full screen.
